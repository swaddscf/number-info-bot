# 🤖 بوت معلومات الأرقام (تيليجرام) — إصدار Node.js

بوت عربي يعرض كل المعلومات المتاحة عن رقم الهاتف، مع نظام **لوحة تحكم للمالك**، **حصة يومية لكل مستخدم**، و**دفع بـ Telegram Stars** للبحث الكامل.

## ✨ مميزات البوت

عند إرسال رقم مثل `+201012345678` يعرض لك:

- 🌍 **الدولة** والمنطقة / المدينة
- 📶 **المشغّل** (اختياري — أضف بياناتك في `carriers.json`)
- 📱 **نوع الخط** (جوال / أرضي / VoIP / مجاني ...)
- ⏰ **المنطقة الزمنية**
- 🧭 **الإحداثيات** + دبوس على الخريطة (موقعه التقريبي)
- 🤖 **حساب تيليجرام**: إذا كان الرقم مسجلاً في تيليجرام يعرض **يوزر الحساب** والاسم وحالة آخر ظهور

### 🛠 لوحة تحكم المالك
- 🔒/🔓 زر لكل ميزة: **الموقع**، **يوزر تيليجرام**، **المنطقة** + زر **قفل الكل** و **فتح الكل**
- 📊 **الحصة اليومية** لكل مستخدم (مثال: بحث واحد في اليوم، أو غير محدود) — عام أو لمستخدم معيّن
- ⭐ **المميزون**: مستخدمون يبحثون **بدون حدود** ويرون كل المعلومات حتى المقفلة (زر في اللوحة + أمر `/premium`)
- 🧾 `/lookup @يوزر` أو `/lookup <آيدي>` — جلب معلومات مستخدم (الآيدي، اليوزر، الاسم، الحالة، البايو)
- 📞 **زر سفلي "تواصل مع المالك"**: قابلة للإضافة/الحذف من الإدارة (`/setcontact` / `/delcontact`)
- 📋 **زر شروط الاستخدام** أسفل حقل الكتابة (ممنوع الابتزاز والتهديد والاستخدام غير المشروع)
- ⭐ **دفع النجوم**: عندما تنفد حصة المستخدم، يدفع عدد نجوم تحدده أنت، ويُفتح له **بحث كامل يعرض كل المعلومات حتى المقفلة** — مرة واحدة لكل رقم
- 📈 إحصائيات (عدد المستخدمين، عمليات اليوم، النجوم المدفوعة)
- 💾 حفظ دائم للبيانات (المستخدمون لكل مستخدم شيء خاص به) في مجلد `data/`

> ⚠️ الموقع تقريبي ويعتمد على الدولة/المنطقة المشغَّل بها الرقم فقط، وليس موقع الشخص الفعلي.

## 🛠️ طريقة التشغيل (Windows — محليًا)

1. تأكد أن Node.js مثبت (اختبار: `node --version`).
2. داخل المجلد شغّل:
   ```
   npm install
   ```
3. انسخ `.env.example` وسمّه `.env` وضع داخله:
   ```
   BOT_TOKEN=توكنك_من_@BotFather
   OWNER_ID=معرفك_الرقمي  ← اجلبه من @userinfobot
   ```
4. شغّل البوت:
   ```
   npm start
   ```

أوامر المالك داخل التيليجرام:
- `/admin` — يعرض لوحة التحكم بالأزرار
- `/setlimit 1` — الحصة اليومية للجميع (0 = غير محدود)
- `/setlimit <معرّف المستخدم> 5` — حصة لمستخدم معيّن
- `/premium <معرّف المستخدم>` — رفع / إزالة مستخدم مميّز (بحث بلا حدود + كل المعلومات)
- `/lookup @username` أو `/lookup <آيدي>` — جلب معلومات مستخدم باليوزر أو الآيدي
- `/setcontact نص` / `/delcontact` — إظهار / حذف زر **تواصل مع المالك** السفلي
- `/setprice 2` — سعر البحث الكامل بالنجوم (0 = تعطيل الدفع)
- `/stats` — الإحصائيات

## 🔑 كيفية الحصول على API_ID و API_HASH (لفحص يوزر تيليجرام)

1. افتح https://my.telegram.org
2. أدخل **رقم هاتفك** ثم تأكيد التسجيل — سيصلك **كود تحقق** في تطبيق تيليجرام.
3. اضغط **API development tools**.
4. املأ النموذج (App title و Short name أي أسماء تريدها) واضغط **Create application**.
5. ستجد صفحة فيها: `api_id` (رقم) و `api_hash` (نص مكوّن من 32 حرفًا ورمزًا).
6. ضعهما في `.env`:
   ```
   TELEGRAM_API_ID=12345678
   TELEGRAM_API_HASH=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
7. شغّل تسجيل الدخول مرة واحدة (يُستخدم مع حسابك الشخصي):
   ```
   npm run setup
   ```
   → أدخل رقمك + كود التحقق الذي يصلك، ثم انسخ ناتج `TG_SESSION=...` وضعه في `.env`.
8. أعد تشغيل البوت: `npm start`

> ⚠️ أمان: **الملف `.env` سرّي** — لا تشاركه ولا ترفعه على GitHub (متجاهل تلقائيًا). `TG_SESSION` يعادل تسجيل دخولك، فاحتفظ به لنفسك.

## ☁️ النشر على Back4app (يعمل 24/7)

1. أضف `TG_SESSION` التي ولّدتها محليًا إلى ملف `.env` قبل النشر (مهم: الجلسة تُنشأ من حسابك — راجع قسم API_ID أعلاه).
2. افتح https://www.back4app.com وسجّل الدخول.
3. من القائمة اختر **Containers** → **Create New App** → *Link GitHub repository* واختر مستودعك (أو import من URL).
4. اضبط الإعدادات:
   - **Branch:** `main`
   - **Root Directory:** `/`
   - **Build/Max Size:** الافتراضي
5. في تبويب **Environment Variables** ضع كل المفاتيح من `.env`:
   | المفتاح | القيمة |
   |---|---|
   | `BOT_TOKEN` | توكن البوت |
   | `OWNER_ID` | معرّفك الرقمي |
   | `TELEGRAM_API_ID` | من my.telegram.org |
   | `TELEGRAM_API_HASH` | من my.telegram.org |
   | `TG_SESSION` | الجلسة المولّدة محليًا |
   | `DATA_DIR` | `/data` |
6. اضغط **Add Volume** → أنشئ حجمًا (Persistent Volume) واربطه بمسار `/data` — **إلزامي** كي تبقى بيانات الحصص والأقفال والنجوم محفوظة بعد كل نشر.
7. في **Container Ports** اجعل المنفذ `8080` (HTTP → Public).
8. اضغط **Deploy** وانتظر انتهاء البناء. عند ظهور `running`، البوت يعمل على مدار الساعة.

> ملاحظة: احذف ملف `.env` المحلي من النشر؟ لا حاجة — `.dockerignore` يستبعده، وكل شيء يُمرَّر عبر المتغيرات في Back4app.

## ☁️ بدائل استضافة مجانية تعمل 24/7 (بدون نوم، وبدون بطاقة ائتمان)

| المنصة | المميزات | بطاقة؟ | ملاحظات |
|---|---|---|---|
| **Koyeb** 🏆 | خدمتا nano (512MB RAM لكل)، **بدون نوم أبدًا**، 0.1 vCPU | ❌ لا | أنسب اختيار — ينشر من GitHub أو Docker مباشرة |
| **Back4app** | حاوية 256MB/0.25CPU، بدون نوم | ❌ لا | الموثّق أعلاه — اربط حجم `/data` |
| **Render** | Background Worker 750 ساعة/شهر، 512MB | ⚠️ يُطلب البعض بطاقة عند التسجيل | اختر **Background Worker** وليس Web Service |
| **Fly.io** | 3 أجهزة VM صغيرة مجانية دائمة | ⚠️ اختيارية | يحتاج أداة `flyctl` |

> ✋ **خلاصة**: إن أرادوا بطاقة في التسجيل (كما في Render)، استخدم **Koyeb** — بدون أي بطاقة ويعمل 24/7 بلا نوم.

### النشر على Koyeb (بدون بطاقة — يُنصح به)
1. ارفع المشروع على GitHub (الخطوات أدناه).
2. سجّل في https://app.koyeb.com (تسجيل بحساب GitHub مباشرة، **بدون بطاقة**).
3. اضغط **Create Service** → **Web Service** → **Deploy from GitHub repository** واختر مستودعك.
4. حدد معمارية النشر: `Node.js` أو **Docker** (الملف `Dockerfile` جاهز) حسب المتاح، **Builder** ليكن الخيار الافتراضي أو Docker.
5. في **Environment variables** أضف: `BOT_TOKEN`، `OWNER_ID`، `TELEGRAM_API_ID`، `TELEGRAM_API_HASH`، `TG_SESSION`، `DATA_DIR=/data`.
6. أضف **Volume** بحجم 512MB+ واربطه بالمسار `/data` (كي تُحفظ الحصص والمميزين).
7. كشف المنفذ **8080** وتأكد أن الـ **HTTP Port** = `8080`، ثم **Deploy**.

### النشر على Render (إن وافقوا دون بطاقة — أو لديك بطاقة)
1. ارفع المشروع على GitHub (الخطوات أدناه).
2. سجّل في https://dashboard.render.com → **New** → **Background Worker**.
3. اختر مستودعك، **Branch** `main`، أمر البناء `npm install`، أمر التشغيل `node bot.js`.
4. في **Environment** ضع: `BOT_TOKEN`، `OWNER_ID`، `TELEGRAM_API_ID`، `TELEGRAM_API_HASH`، `TG_SESSION`، `DATA_DIR=/data`.
5. أضف **Disk** (Persistent Disk) بحجم 1GB واربطه بالمسار `/data` كي تحفظ الأقفال والحصص والمميزين.
6. اضغط **Deploy** — يشتغل فورًا ومستمرًا بدون نوم.

> مع أي منصة: بياناتك في `/data` تحتاج **قرص دائم (Persistent Disk/Volume)** وإلا تُمسح عند كل إعادة نشر.

## 🤖 ميزة "الدفع بالنجوم" — كيف تعمل

- يرسل البوت فاتورة بعملة **XTR (النجوم)** عبر `sendInvoice`.
- عندما تنفد حصة المستخدم اليومية يظهر له زر **"💳 ادفع X ⭐ والبحث كامل"**.
- يُفتح له هذا الرقم فقط (الـ payload = الرقم)، بحث كامل يعرض الموقع والمنطقة ويوزر تيليجرام حتى لو كانت مقفلة.
- للحصول على النجوم المدفوعة: افتح @BotFather → Bot Settings → **Paid Media** / Withdraw، أو عبر https://t.me/BotFather.
